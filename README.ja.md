# AutoClick

**Web ページのボタンを指定した間隔でクリックしながら、自分のマウスを自由に使えます。**

AutoClick は Chrome/Edge 拡張機能と Electron デスクトップアプリで構成されています。操作権限のある Web ページでの繰り返し作業や、EC 運営の補助を想定しています。対象を選び、1 秒以上の間隔を設定すると、回数とログで動作を確認できます。手動でいつでも停止できます。

既存プロジェクトから整理した公開ソース版で、DOM による対象の特定、スケジューリング、ログ、デスクトップのウィンドウ管理を保持しています。業務データ、アカウント設定、ブラウザプロファイル、過去のログ、ビルド済みバイナリは含みません。現状は MVP のソース候補であり、インストールと実際のプラットフォーム上での動作は別途検証が必要です。

作者のプロジェクト：[FateClear](https://fateclear.com) · [X の更新情報](https://x.com/liu_xiaoyu27334)

## 合成デモで動きを確認する

既存の[デモページ](examples/index.html)と[クリック処理](examples/demo.js)から確認できる、想定動作は次のとおりです。今回の文書整理で実行した結果ではありません。

| デモの対象 | 操作と想定結果 |
| --- | --- |
| Demo Item A | DOM クリックを受け取るたびに、ローカルのカウンターが `0` から `1`、`2`……と増えます。 |
| Demo Item B | クリックごとにボタンを作り直し、`讲解` / `取消讲解` を切り替えます。デスクトップ版の状態切り替えと、動的な対象の再特定を確認するための例です。 |

`examples/` は白紙から作成した架空の商品 2 点とローカルカウンターだけのデモです。実業務のスナップショットを匿名化したものではありません。リポジトリのルートで次のコマンドを実行します。

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory examples
```

通常のブラウザまたはデスクトップ版で `http://127.0.0.1:8765/` を開き、まず Demo Item A のカウントボタンを選びます。デスクトップ版では Demo Item B の `讲解` 切り替えとボタンの再生成も確認できます。終了時はターミナルで Ctrl+C を押してデモサーバーを停止してください。今回の整理ではサーバーもブラウザデモも実行していません。

## 最短の使い方：拡張機能を読み込む

1. Chrome/Edge の拡張機能管理ページでデベロッパーモードを有効にします。
2. 「パッケージ化されていない拡張機能を読み込む」を選び、`extension/` を指定します。
3. 操作権限のある HTTP(S) ページを開き、拡張機能のポップアップから対象選択に進みます。ボタンを選び、間隔を設定して開始します。
4. 別の対象を選ぶ前に停止してください。

拡張機能は、選択したページに DOM クリック処理を挿入するため、HTTP/HTTPS サイトへのアクセス権限を宣言しています。ストア審査済みのビルドではありません。ソース整理時に Chrome/Edge へのインストールとブラウザ上の動作は検証していません。

## バージョンと主な機能

| バージョン | エントリーポイント | 用途 |
| --- | --- | --- |
| ブラウザ拡張機能 1.0.0 | `extension/manifest.json` | 既存の Chrome/Edge タブで対象を選び、一定間隔でクリック |
| デスクトップ版 0.1.0 | `desktop/src/main.js` | 独立した操作パネルと対象ブラウザ。主な対象環境は Windows 10/11 x64 |

- ボタン内の文字やアイコンを選んだ場合、対応する意味上のボタン要素を優先して特定します。
- 商品コンテナ、識別子、名前を使い、動的に変化した DOM 上の対象を再特定します。
- 1 秒以上の間隔を設定し、回数とログを確認して手動で停止できます。
- デスクトップ版は絶対時刻に基づいてスケジュールします。遅れた回を飛ばし、遅延分のまとめ実行や重複実行をしません。
- デスクトップ版はページの読み込み失敗や復旧中にクリックを停止し、実行の指示を保持したまま待機時間を調整して再試行します。
- デスクトップ版の `讲解` / `取消讲解` の状態切り替えでは、1 回の成功した処理に DOM クリックが 2 回含まれる場合があります。成功した処理回数は物理的なクリック回数とは異なります。

拡張機能とデスクトップ版は別々の実装で、動作は完全には同一ではありません。拡張機能はブラウザのバックグラウンドタイマーを使うため、長時間のバックグラウンド処理、スリープ、Service Worker の再起動をまたぐ継続動作は保証しません。クロスオリジンの iframe、Canvas、独自の自動操作対策、実際のマウス入力を必要とするページも保証範囲外です。ログイン、CAPTCHA、権限の確認は利用者が手動で行います。

## デスクトップ版を起動する

Node.js 22 以降が必要です。以下は利用者が実行するインストールと起動の手順です。今回の整理では依存関係のダウンロードや Electron の起動を行っていません。

```sh
cd desktop
npm ci
npm start
```

操作パネルに HTTP(S) アドレスを入力し、必要に応じて手動でログインして、ボタンを選び開始します。ウィンドウを閉じるとトレイに隠れます。プロセスを終了するにはトレイのメニューで「終了」を選びます。Mac では依存関係をインストール後に `desktop/启动Mac本地测试.command` をダブルクリックできます。Mac で起動できても Windows の検証が完了したことにはなりません。

Windows ポータブル版のビルド入口は `npm run dist:win` です。パッケージング用の依存関係、署名、プラットフォーム互換性、配布時の第三者ライセンス表記は、リリース環境で別途確認が必要です。署名済みバイナリ、自動更新機能、インストーラー、ストアへの公開実績は含みません。

## ローカル検証と成熟度

npm の依存関係をインストールせずに、リポジトリのルートから実行できます。

```sh
node tools/test.js
node tools/check-syntax.js
```

単体テストは Node の標準ライブラリ、仮想 DOM、合成入力だけを使用します。一時ディレクトリのテストは、自分で作成した一時ディレクトリのみを削除します。デスクトップ版の任意の `npm run smoke` は、新しい一時プロファイルで Electron とローカル HTTP サーバーを起動します。ソース整理時にこのチェックは実行していません。

現状は MVP のソース候補です。Node の単体テストや構文チェックだけでは、実際のサイトとの互換性、Windows のトレイやスリープ時の挙動、長時間のバックグラウンド動作、ブラウザ拡張機能のライフサイクルの正しさは確認できません。別途、手動での受け入れ確認が必要です。

## データとプライバシー

ソースの利用に API キーや `.env` は不要です。実行時、拡張機能は対象の記述、状態、ログを `chrome.storage.local` に保存します。デスクトップ版は Electron のアプリケーションデータディレクトリに状態、ログ、独立したブラウザセッションを保存します。対象の記述やエクスポートしたログには、ページ URL、商品テキスト、DOM 属性が含まれる場合があり、一部の処理では完全な URL を保持します。**実行記録は公開サンプルではありません。確認せずにリポジトリや公開 issue に投稿しないでください。** 既存のプロファイルと実行記録はすべて除外しています。

元のアイコンは含めていません。現在のアイコンは `tools/generate-icons.py` が Python の標準ライブラリだけで決定的に生成するオリジナル画像です。この実験的なソース版には上記の未検証範囲が残っています。ソース公開は、ストア審査や実プラットフォームでの検証完了を意味しません。
