# AutoClick

[English](README.en.md)

在网页里选择一个按钮，按设定间隔重复点击，同时继续使用自己的鼠标。AutoClick 包含 Chrome/Edge 扩展和 Electron 桌面版，适合有明确授权的网页重复操作与电商中控辅助。

这是从已有项目整理的源码候选包，保留原有 DOM 定位、调度、日志和桌面窗口管理。没有附带业务数据、账号配置、浏览器档案、历史日志或预编译程序。许可证为 [MIT](LICENSE)，第三方边界见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

| 版本 | 入口 | 适用范围 |
| --- | --- | --- |
| 浏览器扩展 1.0.0 | `extension/manifest.json` | 在现有 Chrome/Edge 标签页选择目标，按间隔点击 |
| 桌面版 0.1.0 | `desktop/src/main.js` | 独立控制面板和目标浏览器，Windows 10/11 x64 为主要目标 |

## 能做什么

- 选择按钮内部文字或图标时，优先识别所属语义按钮。
- 通过商品容器、标识或名称重新定位动态页面中的目标。
- 设置至少 1 秒的点击间隔，查看次数和日志，手动停止。
- 桌面版采用绝对时间调度；迟到时跳过旧时点，不补点，不并发点击。
- 桌面版在页面加载失败或恢复时暂停点击，保留运行意图并退避重试。
- 桌面版对“讲解 / 取消讲解”按钮支持受控状态切换；一次调度可能包含两次 DOM 点击，不能把成功轮数等同于物理点击数。

扩展与桌面版是两种独立实现，并非完全相同的行为。扩展使用浏览器后台定时器，不保证长时间后台、休眠或 Service Worker 重启后的持续运行。跨域 iframe、Canvas、自定义反自动化机制及依赖真实鼠标事件的页面不在当前保证范围；登录、验证码和权限由使用者手动完成。

## 使用扩展

1. 在 Chrome/Edge 扩展管理页开启开发者模式。
2. 选择“加载已解压的扩展程序”，指向 `extension/`。
3. 打开自己有权限操作的 HTTP(S) 网页，在弹窗中点击“在网页中选择目标”。
4. 选中按钮，设置间隔，再开始。切换目标前先停止。

扩展声明 HTTP/HTTPS 站点访问权限，用于向使用者选择的网页注入 DOM 点击逻辑。它不是商店已审核版本；本次整理未验证 Chrome/Edge 的安装与运行。

## 使用桌面版

需要 Node.js 22 或更新版本；以下安装和启动命令供使用者自行执行，本次整理没有联网安装或启动 Electron。

```sh
cd desktop
npm ci
npm start
```

在控制面板输入 HTTP(S) 地址，手动登录目标站点，选择按钮后开始。关闭窗口会隐藏到托盘；从托盘选择“退出”才会结束进程。Mac 可在安装依赖后双击 `desktop/启动Mac本地测试.command`，但 Mac 上运行不代表 Windows 验收通过。

Windows portable 的构建入口为 `npm run dist:win`。打包依赖、签名、平台兼容性及分发所需第三方声明仍需在发布环境检查；本包没有签名、自动更新、安装包或商店发布记录。

## 合成演示

`examples/` 完全从空白编写，只有两个虚构商品和本地计数器，不包含业务快照。可在包根目录运行以下命令：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory examples
```

然后在普通浏览器或桌面版打开 `http://127.0.0.1:8765/`。先选择 Demo Item A 的计数按钮；桌面版还可以测试 Demo Item B 的“讲解”切换按钮及按钮重建。结束后在终端按 Ctrl+C 关闭演示服务。本次整理未启动此服务或执行浏览器演示。

## 本地验证

从包根目录运行，无需安装 npm 依赖：

```sh
node tools/test.js
node tools/check-syntax.js
```

单元测试只使用 Node 标准库、虚拟 DOM 和合成输入。临时目录测试仅创建并删除自己生成的临时目录。桌面版的可选 `npm run smoke` 会启动 Electron 和本地 HTTP 服务，使用新建临时档案；它未在此次整理中运行。

当前成熟度为 MVP 源码候选。Node 单测或语法检查不能证明真实站点兼容性、Windows 托盘/休眠行为、长期后台稳定性或浏览器扩展生命周期正确；这些仍需独立手动验收。

## 数据与隐私

源码包不需要 API 密钥或 `.env`。运行时，扩展会在 `chrome.storage.local` 保存目标描述、状态和日志；桌面版会在 Electron 的应用数据目录保存状态、日志及独立浏览器会话。目标描述和导出的日志可能包含网页 URL、商品文字和 DOM 属性，部分路径会保留完整 URL。**运行记录不是公开样例，不要直接提交到仓库或 issue**。本包排除了所有既有用户档案和运行记录。

原图标未带入；包内图标由 `tools/generate-icons.py` 以标准库确定性生成。该源码实验版保留上述未验证范围；公开源码不代表商店或真实平台验收完成。
